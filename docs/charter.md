# 同勘 GeoCrew 章程

> 状态：已采纳（2026-11-25）。改动本文要走 PR，并在文末"变更记录"里加一行。

## 1. 定位

同勘 GeoCrew 是开源的野外地质与 GIS 工具，由安卓客户端、自部署服务端和协同协议三部分组成。四个目标：

1. **完整的移动端 GIS**：QGIS 有的功能，同勘都要有类似的功能，按能力来衡量，不移植 QGIS，也不追求与它兼容。另外要有插件生态。
2. **强大的野外地图**：地图功能对标并超过奥维互动地图。我们只提供接口，用户自带 Key。另有指南针、产状测量等野外工具。
3. **多人实时工作区**：团队部署自己的服务端，发起远程多人协作。
4. **内置 AI**：AI 直接操作同勘自身的功能，大幅降低学习成本。模型用用户自己的 Key，可以是个人的，也可以是服务端共享的。

## 2. 第一批用户

国内的野外地质小组。他们同时需要上面四样东西，所以产品范围按他们的需要收紧，但架构仍按通用 GIS 来设计。

## 3. 原则

- **离线优先**：所有操作先存在本机，有网时再同步。没有服务端，也能完整地单机使用。
- **数据自主**：项目方不托管任何用户数据，不提供统一的 Key，也不分发地图数据。
- **开放格式**：工程用 GeoPackage 保存；交换数据用 GDAL 支持的通用格式。
- **协议先行**：接口要改，先改 `protocol/`，再改实现。
- **简单优先**：能用简单办法解决的，不搭复杂的机制；尽量用成熟的开源组件，不自己造轮子。

## 5. v0.1 的范围与完成标准

v0.1 只做一条纵向闭环：

> 建工程 → 天地图底图 → 记地质点（产状、照片）→ 编辑 → 导出 GPKG / KML → 两台手机经服务端同步，且不丢数据。

完成标准（每个里程碑都适用）：

- 负责人在真机上走通，并留下录屏或日志；
- CI 全部通过，包括同步的随机交错测试；
- README 只写真机验证过的功能，没验证的标"实验"。

## 7. 不做的事

- **开车导航**：交给高德、百度，我们只传真实坐标给它们。
- **托管服务和统一 Key**：项目方不托管数据，也不提供共用的 Key。
- **分发地图数据**：离线底图和地名库只提供工具，数据由用户自备。
- **低端机和 32 位设备**：不专门适配。
- **应用商店**：暂时不上，只在 GitHub Releases 和官网提供直装。
- **鸿蒙 NEXT 和 iOS**：暂时不做，但要留余地，协议和各种规则都写成文档和共用测试样例。
- **操作别的应用**：AI 只操作同勘自己的功能。
- **移植或兼容 QGIS**：我们做的是功能类似，不是行为一样。

## 8. 平台基线

- 最低安卓 12（API 31），编译目标用最新版本。
- 只支持 64 位：arm64-v8a，另外为模拟器提供 x86_64。
- 申请"所有文件访问"权限，数据放在 `/sdcard/GeoCrew`，详见 [ADR 0002](adr/0002-android-baseline.md)。

## 9. 质量与流程

- 每个改动都走 PR：一个 PR 只做一个纵向切片，改动尽量控制在约 500 行以内，不算生成文件和测试数据。
- PR 先由 AI 评审，CI 必须通过。负责人很少看代码，主要做里程碑的真机验收，有空时看看架构决策和协议改动。
- AI 代理的工作规则写在各目录的 `CLAUDE.md` 里。
- 往后推的事一律写进[待办](backlog.md)。
