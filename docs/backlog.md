## 已定的约束（2026-11-25）

- **发布**：只走 GitHub Releases 和官网直装，不上应用商店。
- **代码审查**：每个 PR 由 AI 评审，CI 把关。负责人只做里程碑的真机验收，有空时看关键设计。
- **平台**：
  - 只做安卓。
  - 鸿蒙 NEXT 和 iOS 先不做，但要留余地：协议、合并规则和权限规则都写成文档和两端共用的测试样例，不绑死在 Kotlin 里。
- **安卓版本与机型**：
  - 只支持 64 位（arm64、x86_64）。
  - 最低系统版本定为安卓 12（API 31），编译目标用最新版本。
  - 不专门适配低端机。
  - 真机测试只用一台三星 Galaxy S24 Ultra（安卓 16），性能指标按它的实测来定，不另找中端参考机（负责人 2026-11-26）。
  - 安装包体积不设上限：能省则省，但不为体积砍功能。
- **地图数据**：项目方不托管、不分发任何地图数据。用户自带 Key，我们只负责接入主流图源。不需要 Key 的公开源（OSM 在线瓦片、AWS 地形数据）保留为可选预设，由用户直接连接提供方。离线底图和地名库只提供工具，数据由用户自备。
- **工程文件**：同步中的工程 GeoPackage 只由应用写入，外部程序只能读，要改就改副本。

## 完整的 GIS 功能（负责人 2026-11-26 要求，分批做）

现在的图层页只管点图层，菜单里也只有几项，离"完整的移动 GIS"差得远。下面这些都要做，不要求一次做完，每批照常走 PR。上面 M2 里已有的条目（坐标的快捷获取、转移图层、图层页的显示控制、地质点采集）算在这里面，做完时两边一起勾。

- [ ] **图层管理页**做成完整的 GIS 图层管理，取代现在只列点图层的页面：
  - 支持所有图层：矢量（点、线、面；工程里的和外部文件里的）、栅格（GeoTIFF 等）、在线底图和瓦片服务（天地图、XYZ、WMS、WMTS，见 ADR 0015）、离线瓦片包（MBTiles 等）、高程和山体阴影；图层可以分组。
  - 添加图层：新建、从文件添加、添加在线服务、添加离线包。
  - 每个图层有成套的设置，字段只是其中一项：显示和隐藏、透明度、上下顺序、符号和样式（ADR 0006）、标注、按比例尺显示、筛选条件、坐标系、属性表、字段（增、删、改名）、缩放到图层、图层信息（来源、要素数、范围、坐标系）、改名、复制、删除、导出、编辑开关、捕捉。
- [x] 分级菜单的框架和第一批工具（2026-11-26）：第一级是图层、地图、测量、数据、工程，点进去是工具，返回回到上一级；只列做好的工具。地图：全图、跳到坐标、指北；测量：测距离（沿 WGS84 椭球）、测面积（按地球平均半径的球面算，野外够用）；数据：导出；工程：工程设置、关闭工程。

  - 编辑：点选、框选、套索选择，移动、改节点、删除、复制粘贴，转移到其他图层，捕捉设置。
  - 测量：距离、面积、方位角，拾取坐标。
  - 定位与导航：GPS 状态、我的位置、轨迹记录、导航到点（开车导航交给高德或百度）。
