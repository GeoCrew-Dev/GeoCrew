这里记录已经定下、但还没做或排在后面的事，免得忘记。完成一项就勾掉一项，新的待办写到对应阶段下面。主仓库推到 GitHub 以后，再同步成 Issues 和里程碑。

各项决定是怎么来的，见[计划评审](reviews/2026-11-25-plan-review.md)。以后的架构决策写在 `docs/adr/`。

## 已定的约束（2026-11-25）

- **发布**：只走 GitHub Releases 和官网直装，不上应用商店。
- **代码审查**：每个 PR 由 AI 评审，CI 把关。负责人只做里程碑的真机验收，有空时看关键设计。
- **平台**：
  - 只做安卓。
  - 鸿蒙 NEXT 和 iOS 先不做，但要留余地：协议、合并规则和权限规则都写成文档和两端共用的测试样例，不绑死在 Kotlin 里。
- **安卓版本与机型**：
  - 只支持 64 位（arm64、x86_64）。
  - 最低系统版本在安卓 12 和 14 之间选，不超过 14。
  - 不专门适配低端机，性能指标按一台中端参考机型来定。
- **地图数据**：项目方不托管、不分发任何地图数据。用户自带 Key，我们只负责接入主流图源。
- **工程文件**：同步中的工程 GeoPackage 只由应用写入，外部程序只能读，要改就改副本。
