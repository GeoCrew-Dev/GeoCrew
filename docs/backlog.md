## 已定的约束（2026-11-25）

- **发布**：只走 GitHub Releases 和官网直装，不上应用商店。
- **代码审查**：每个 PR 由 AI 评审，CI 把关。负责人只做里程碑的真机验收，有空时看关键设计。
- **平台**：
  - 只做安卓。
  - 鸿蒙 NEXT 和 iOS 先不做，但要留余地：协议、合并规则和权限规则都写成文档和两端共用的测试样例，不绑死在 Kotlin 里。
- **安卓版本与机型**：
  - 只支持 64 位（arm64、x86_64）。
  - 最低系统版本定为安卓 12（API 31），编译目标用最新版本。
  - 不专门适配低端机。
  - 真机测试只用一台三星 Galaxy S24 Ultra（安卓 16），性能指标按它的实测来定，不另找中端参考机（负责人 2026-11-26）。
  - 安装包体积不设上限：能省则省，但不为体积砍功能。
- **地图数据**：项目方不托管、不分发任何地图数据。用户自带 Key，我们只负责接入主流图源。不需要 Key 的公开源（OSM 在线瓦片、AWS 地形数据）保留为可选预设，由用户直接连接提供方。离线底图和地名库只提供工具，数据由用户自备。
- **工程文件**：同步中的工程 GeoPackage 只由应用写入，外部程序只能读，要改就改副本。

## 完整的 GIS 功能（负责人 2026-11-26 要求，分批做）

现在的图层页只管点图层，菜单里也只有几项，离"完整的移动 GIS"差得远。下面这些都要做，不要求一次做完，每批照常走 PR。上面 M2 里已有的条目（坐标的快捷获取、转移图层、图层页的显示控制、地质点采集）算在这里面，做完时两边一起勾。

**地图应用的结构（ADR 0017，负责人 2026-11-28 提的两点，方案请 Fable 评过）**：GIS 和野外地图共用一棵图层树和一个工具注册表，一张表仍是一种几何。按这个顺序做：

- [x] 加要素先选点、线、面（2026-11-28）：定点打开的面板顶上是"点 | 线 | 面"，记住上次的选择，下面只列能放这种要素的图层，"新建图层"按选中的种类预设；混合几何（`GEOMETRY`）的图层三种都列。
- [x] 图层列表改成折叠行（2026-11-28）：每行是显隐、图例色块（点、线、面各有样子，分类样式显示前几种颜色）、名称和数量、⋮，眼睛和分节标题对齐；点开看完整图例和不透明度。矢量图层的 ⋮：缩放到图层、属性表、样式、字段（底部面板，各字段自己的菜单和添加）、上移、下移、导出（单个图层存成 KML 或 GeoPackage，`project.export` 加了 `layer`）、建一个同样的图层、改名、图层信息、删除。栅格的 ⋮：缩放、灰度/山体阴影/分层设色、移除。

- [x] 图层分组（2026-11-28，`core:layers`）：图层的 ⋮ 里"移到分组"（已有的组、新建分组、移出分组），组的 ⋮ 里上移、下移、改名、取消分组；组的眼睛隐藏组内全部图层，组能折叠；组内图层缩进，画在组的位置。分组只在本机，见 ADR 0017 的补充。

- [x] 内置文件管理器（2026-11-27）：主页右上角和地图菜单"数据 → 文件"进入。有"所有文件访问"时能看整个手机存储，上面有 GeoCrew、下载、微信（有这个文件夹时）、手机存储几个快捷位置，下面是可以点的路径；没有时只看 GeoCrew 文件夹。文件夹在前，按名称（数字按大小，D2 在 D10 前面）、时间或大小排，可以显示隐藏文件；图标分文件夹、矢量、栅格、图片、压缩包、文档。点文件或右边的"更多"：打开（用其他应用）、分享、复制、移动、重命名、删除（文件夹会说里面有几项）；复制和移动时底下出现粘贴条，走到哪个文件夹就粘贴到哪里，重名的自动加"(2)"。所有操作都是动作（`file.list`、`file.folder.make`、`file.rename`、`file.copy`、`file.move`、`file.delete`，在新模块 `core:files` 里）：AI、插件只能动 GeoCrew 文件夹（ADR 0011）；打开的工程的文件、手机存储和 GeoCrew 文件夹本身不能改。
  - [x] 多选（2026-11-27，负责人要求参考 MT 管理器，但不用那么全、不要双栏，用我们的 MD3 样式）：长按一项开始选，再点别的项加选或取消，顶栏显示已选几项、能全选，底栏是复制、移动、分享（选了文件夹时不能分享）、重命名（只选一项时）、属性、删除；返回键先取消选择。属性：一项时写位置（能复制路径）、修改时间，大小和包含几个文件、几个文件夹由新动作 `file.info` 统计。右上角的搜索按名字筛当前文件夹。
  - [x] GIS 文件的属性（2026-11-27）：矢量、栅格文件的"属性"里多出格式、坐标系，栅格还有像素、波段、像元大小、经纬度范围，矢量有各图层的几何类型和要素数。文件在独立进程里读（ADR 0003，动作 `file.probe`），坏文件只说"读不了这个文件"。
  - [x] 导入矢量数据（2026-11-27，ADR 0002）：文件管理器里矢量文件和 zip 显示"导入到「工程」"，先在独立进程里试读；有多个图层时勾选导入哪些。GeoPackage、Shapefile（zip 里的也直接读）、GeoJSON、KML、GPX 等的图层连同字段、要素和坐标系复制成工程图层（动作 `layer.import`）；一个图层的按文件名命名，重名加编号；没有坐标系的不收，失败不留半个图层。
  - [ ] 别的应用"用同勘打开"和分享过来的文件（2026-11-27）：复制进 GeoCrew 文件夹的"导入"（GDAL 按路径读，拿不到 content 地址），重名的整批编号（Shapefile 的几个文件一起）；文件管理器在那里打开，说收到几个。没有打开的工程时，文件菜单里是"导入到工程"/"添加到工程"，先选工程，导入后关回去，提示条上能直接打开那个工程。接收 GIS 格式和类型不明的文件（.shp、.gpkg 常是这样），不接收图片、文档。
  - [ ] 下一步：导入到新建工程或临时工程；外部图层就地编辑（v0.2）；大文件分批读、在后台跑；压缩和解压（中文文件名按 GBK 认）。
- [ ] **分级菜单**：菜单按类分级，放进大量 GIS 和地图工具。每个工具都是动作注册表里的动作（ADR 0010），AI 和插件也能调用、也能往菜单里加（ADR 0011、0012）。先定菜单的分类和层级，工具再一批批加：
  - 地图：底图切换、书签、跳到坐标或地名、全图、锁定旋转、截图和出图。
  - 图层：图层管理、添加数据、属性表。
  - 编辑：点选、框选、套索选择，移动、改节点、删除、复制粘贴，转移到其他图层，捕捉设置。
  - 测量：距离、面积、方位角，拾取坐标。
  - 定位与导航：GPS 状态、我的位置、轨迹记录、导航到点（开车导航交给高德或百度）。
  - 野外工具：罗盘测产状、拍照、录音（各专业的工具由插件提供）。
  - 数据：导入、导出、离线地图下载（只对条款允许下载的图源，见 ADR 0015 2026-11-27 的补充）、工程快照。
  - 分析：缓冲区、统计、坐标换算等。
