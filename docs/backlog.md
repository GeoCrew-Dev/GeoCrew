## 已定的约束（2026-11-25）

- **发布**：只走 GitHub Releases 和官网直装，不上应用商店。
- **代码审查**：每个 PR 由 AI 评审，CI 把关。负责人只做里程碑的真机验收，有空时看关键设计。
- **平台**：
  - 只做安卓。
  - 鸿蒙 NEXT 和 iOS 先不做，但要留余地：协议、合并规则和权限规则都写成文档和两端共用的测试样例，不绑死在 Kotlin 里。
- **安卓版本与机型**：
  - 只支持 64 位（arm64、x86_64）。
  - 最低系统版本定为安卓 12（API 31），编译目标用最新版本。
  - 不专门适配低端机。
  - 真机测试只用一台三星 Galaxy S24 Ultra（安卓 16），性能指标按它的实测来定，不另找中端参考机（负责人 2026-11-26）。
  - 安装包体积不设上限：能省则省，但不为体积砍功能。
- **地图数据**：项目方不托管、不分发任何地图数据。用户自带 Key，我们只负责接入主流图源。不需要 Key 的公开源（OSM 在线瓦片、AWS 地形数据）保留为可选预设，由用户直接连接提供方。离线底图和地名库只提供工具，数据由用户自备。
- **工程文件**：同步中的工程 GeoPackage 只由应用写入，外部程序只能读，要改就改副本。

  - [x] 编辑形状（2026-11-26）：线、面的表单里"编辑形状"，带着原有节点回到绘制，能接着加点、撤销最后的节点，完成后改这个要素的几何，一步撤销；多部分的和带洞的面先不行。
  - [x] 节点编辑（2026-11-27）：画线、画面和"编辑形状"时，点一个节点选中它（变大变蓝），可以移动（地图移到它那里，它跟着十字走，按"放在这里"放下）、删除，选中时"加节点"加在它后面；每条边中间有空心小圆，点一下就在那里插入一个节点并选中。撤销改成按步撤销任何改动，返回键先取消移动、再取消选择、再撤销，没得撤销时退出绘制。移动用十字定位而不是手指拖，手指不挡住节点，也和定点、加节点的做法一致。
  - [x] 捕捉到已有要素的节点和边（2026-11-27）：画线、面和移动节点时，十字准星或点地图的位置在 16 dp 内靠近已有要素（各图层的点、线、面）或正在画的图形自己的节点时，吸到节点上，否则吸到最近的边上；用要素的原始坐标，不用地图按瓦片切过的。吸住时准星处有紫色圆圈。不吸正在改形状的那个要素、正在移动的节点。菜单"编辑 → 捕捉"开关，默认开，可以放到工具栏上。
  - [ ] 捕捉的下一步：定点时也能吸到线和面上；只吸某些图层；吸附距离可调。
  - [x] GPS 轨迹记录（2026-11-27）：菜单"定位 → 记录轨迹"。用"定位"类前台服务记 GNSS，锁屏也记，不申请"始终允许"；每 2 秒一个位置，可能偏差超过 50 米的不要，离上一点不到 5 米（或不到精度的一半）的不记。每个点马上写进应用私有目录的文件，应用被杀后轨迹以"已暂停"回来。地图上显示正在记的线和记录条（长度、用时、暂停、继续、结束、丢弃），通知栏有计时。结束时选一个线图层或新建"轨迹"图层（模板 track：名称、描述、开始时间、结束时间、长度），表单里自动填好，存成一条线，能撤销。一次只记一条，属于开始时的工程；离开工程照样记，在别的工程里点"记录轨迹"会说是哪个工程在记。
  - [ ] 轨迹的逐点时间和高程（协议 v0 §6.13 的 `times_s`）：等表单能隐藏字段，或几何能带 M、Z 值时再存；照片按拍摄时间落点、带时间的 GPX 导出都要用。记录间隔和最小距离做成设置。
  - [x] 线、面在同类图层之间转移（2026-11-26）：表单里的"移到其他图层"只列同类（点、线、面）的图层，也能新建一个一样的图层转过去。
  - [x] 线和面的名称标注（2026-11-27）：线的名称标在线长度的中点（多部分的取最长的一段），顺着那里的走向转，字头朝上，地图转时跟着转；面的名称标在外环的形心（多部分的取最大的一块），始终正着。和点名一样画成图片，不用字体文件，离线、中文都行；互相避让，图层隐藏时不显示，跟着图层的不透明度。
  - [x] 选哪个字段当标注（2026-11-27）：样式页的"标注"一栏选字段或"无"，默认是名称字段；点、线、面都按它标（ADR 0006）。
  - [ ] 标注的下一步：标注的字号、颜色，按比例尺显隐；长线上重复标；凹多边形的标注点放在面内。
  - [x] 主页卡片分别写点、线、面的数目（2026-11-26），只有点时照旧。
- [x] 分级菜单的框架和第一批工具（2026-11-26）：第一级是图层、地图、测量、数据、工程，点进去是工具，返回回到上一级；只列做好的工具。地图：全图、跳到坐标、指北、底图（天地图影像、矢量、地形，各带注记，按工程记在手机上；图层页的底图名称跟着变）、截图（只有地图，不带按钮，PNG 存进导出文件夹，能分享）、书签（存当前视图，存在工程里，点一下回去，删除先问）、锁定旋转（北一直朝上，两指不能转，记在应用设置里）；测量：测距离（沿 WGS84 椭球）、测面积（按地球平均半径的球面算，野外够用）、测方位角（两点，沿椭球，同时给磁方位角（按世界地磁模型的磁偏角）和距离；第三下重新开始）、拾取坐标（十进制度和度分秒，复制成"纬度, 经度"）；分析：坐标换算（原坐标系、目标坐标系都用坐标系选择器，输入时就换算，能取地图中心、互换、复制结果、在地图上定位）；数据：导出；工程：工程设置、关闭工程。
  - [x] 地图工具栏（2026-11-27，负责人要的"完整 GIS 工具栏"）：地图右边那列半透明按钮可以自己定：菜单里的工具（图层、撤销重做、添加要素、全图、跳到坐标、指北、底图、截图、书签、锁定旋转、四种测量、我的位置、记录轨迹、坐标换算、导出、文件、工程设置、关闭工程）都能放上去，在"地图 → 编辑工具栏"里加入、移出、上下调顺序、恢复默认（默认还是图层、撤销、重做、我的位置），记在手机上。一列放不下就往左再排一列（最多两列：工具栏只放用户常用的，全部工具在菜单里）；正在用的工具（测量、锁定旋转、记录中的轨迹）按钮会亮；标题下面的面板让开工具栏。菜单和工具栏用同一份工具定义（`MapTool`），菜单里也多了撤销、重做、我的位置。
  - [ ] 地图视图类的工具（跳到坐标、全图、指北、测量）和轨迹的开始、暂停、结束现在在界面里直接做，不改数据；做 AI 助手时注册成动作，让 AI 也能用（ADR 0010，`protocol/docs/actions.md` 的 `start_track`、`stop_track`）。存轨迹已经走动作（`feature.add`）。
- [x] 内置文件管理器（2026-11-27）：主页右上角和地图菜单"数据 → 文件"进入。有"所有文件访问"时能看整个手机存储，上面有 GeoCrew、下载、微信（有这个文件夹时）、手机存储几个快捷位置，下面是可以点的路径；没有时只看 GeoCrew 文件夹。文件夹在前，按名称（数字按大小，D2 在 D10 前面）、时间或大小排，可以显示隐藏文件；图标分文件夹、矢量、栅格、图片、压缩包、文档。点文件或右边的"更多"：打开（用其他应用）、分享、复制、移动、重命名、删除（文件夹会说里面有几项）；复制和移动时底下出现粘贴条，走到哪个文件夹就粘贴到哪里，重名的自动加"(2)"。所有操作都是动作（`file.list`、`file.folder.make`、`file.rename`、`file.copy`、`file.move`、`file.delete`，在新模块 `core:files` 里）：AI、插件只能动 GeoCrew 文件夹（ADR 0011）；打开的工程的文件、手机存储和 GeoCrew 文件夹本身不能改。
  - [x] 多选（2026-11-27，负责人要求参考 MT 管理器，但不用那么全、不要双栏，用我们的 MD3 样式）：长按一项开始选，再点别的项加选或取消，顶栏显示已选几项、能全选，底栏是复制、移动、分享（选了文件夹时不能分享）、重命名（只选一项时）、属性、删除；返回键先取消选择。属性：一项时写位置（能复制路径）、修改时间，大小和包含几个文件、几个文件夹由新动作 `file.info` 统计。右上角的搜索按名字筛当前文件夹。
  - [x] GIS 文件的属性（2026-11-27）：矢量、栅格文件的"属性"里多出格式、坐标系，栅格还有像素、波段、像元大小、经纬度范围，矢量有各图层的几何类型和要素数。文件在独立进程里读（ADR 0003，动作 `file.probe`），坏文件只说"读不了这个文件"。
  - [x] 导入矢量数据（2026-11-27，ADR 0002）：文件管理器里矢量文件和 zip 显示"导入到「工程」"，先在独立进程里试读；有多个图层时勾选导入哪些。GeoPackage、Shapefile（zip 里的也直接读）、GeoJSON、KML、GPX 等的图层连同字段、要素和坐标系复制成工程图层（动作 `layer.import`）；一个图层的按文件名命名，重名加编号；没有坐标系的不收，失败不留半个图层。
  - [ ] 下一步：别的应用"用同勘打开"、分享过来的文件也走导入；导入到其他工程、新建工程或临时工程；外部图层就地编辑（v0.2）；大文件分批读、在后台跑；压缩和解压（中文文件名按 GBK 认）。
- [ ] **分级菜单**：菜单按类分级，放进大量 GIS 和地图工具。每个工具都是动作注册表里的动作（ADR 0010），AI 和插件也能调用、也能往菜单里加（ADR 0011、0012）。先定菜单的分类和层级，工具再一批批加：
  - 地图：底图切换、书签、跳到坐标或地名、全图、锁定旋转、截图和出图。
  - 图层：图层管理、添加数据、属性表。
  - 编辑：点选、框选、套索选择，移动、改节点、删除、复制粘贴，转移到其他图层，捕捉设置。
  - 测量：距离、面积、方位角，拾取坐标。
  - 定位与导航：GPS 状态、我的位置、轨迹记录、导航到点（开车导航交给高德或百度）。
  - 野外工具：罗盘测产状、拍照、录音（各专业的工具由插件提供）。
  - 数据：导入、导出、离线地图下载（只对条款允许下载的图源，见 ADR 0015 2026-11-27 的补充）、工程快照。
  - 分析：缓冲区、统计、坐标换算等。
