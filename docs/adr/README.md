# 架构决策记录（ADR）

状态说明：

- **已采纳**：已经定下，按它实施。
- **草案**：方向已定，要等 M1 的技术验证确认。
- **已取代**：被后来的 ADR 取代。

## 模板

```markdown
# 编号 标题

- 状态：已采纳 / 草案 / 已取代（日期）
- 相关：其他 ADR、待办条目

## 背景
要解决什么问题，受到哪些约束。

## 决定
定了什么，写成能照着实施的条目。

## 理由
为什么这样定，比较过哪些其他做法。

## 代价与后果
要付出什么，以后会受什么限制，哪些还没定。

## 状态
当前状态和需要的验证。

## 相关
链接。
```
