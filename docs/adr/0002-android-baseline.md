# 0002 安卓平台基线

## 背景

要定下来的有这些：最低支持哪个系统版本、支持哪些 CPU 架构、文件放在哪里、应用怎么分发。

最低版本的考虑：野外常用的三防机，以及还能安装 APK 的鸿蒙 4 及更早的华为手机，系统兼容层大多停在安卓 12 左右。负责人不打算专门适配低端机。

## 决定

- **系统与架构**：
  - 最低安卓 12（API 31），编译目标用最新版本。
  - 只出 64 位：arm64-v8a，另外为模拟器出 x86_64。不支持任何 32 位设备。
- **存储**：
  - 申请"所有文件访问"权限（`MANAGE_EXTERNAL_STORAGE`）。
  - 应用自己创建 `/sdcard/GeoCrew`，所有路径直接读写。
  - 在这个文件夹里放一个 `.nomedia`，让野外照片不出现在系统相册里。
  - 用户拒绝授权时，退回到应用自己的文件夹，只能导入，不能就地编辑。
- **分发与更新**：
  - 只在 GitHub Releases 和官网直装，不上应用商店。
  - 应用内检查更新，只看带 `android-v*` 前缀的版本。
  - 官网写各品牌的安装引导，包括华为的纯净模式，以及小米、OPPO、vivo 的外部来源安装提示。
- **临时工程**：
  - 可以手动建，也可以在导入时选。
  - 离开时：没改动就直接删除；有新增或修改的记录，先问用户是删除还是转为正式工程。
  - 临时工程不能加入工作组。
- **导入流程**：
  1. 文件来自"用其他应用打开"、分享，或者在应用内选择。
  2. 先在独立进程里识别内容：支不支持、有几个图层、多少要素、什么坐标系。
  3. 用户选择导入到当前工程、其他工程、新建工程，或者新建临时工程。
  4. 数据转换成工程图层。

  在应用内浏览文件时，也可以选"直接打开"，进行就地编辑，见 [ADR 0005](0005-edit-buffer.md)。
- **性能**：按一台中端参考机型来定性能指标，见[性能预算](../budgets.md)。

## 理由

- 安卓 12 起步能把鸿蒙 4 的华为手机和较老的三防机都覆盖进来。安卓 12 到 14 新增的那些规则，只要编译目标是最新版本，本来就得遵守。
- "所有文件访问"权限让 GDAL 和 SQLite 可以直接按路径读写，省掉系统文件授权那一层桥接，也省掉复制进应用文件夹的流程。
- 不上应用商店，这个权限就不用向商店解释。

## 代价与后果

- 国产手机安装外部 APK 时会弹警告，要靠安装引导。
- 如果以后要上应用商店，这个权限要写明用途，还要补备案，详见[合规清单](../compliance.md)。
- 安卓 12 以下的设备用不了。

## 状态

已采纳（2026-11-25）。M1 要在一台鸿蒙 4 手机上确认它报的 API 级别。
