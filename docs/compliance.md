# 合规清单

> 状态：v0.1 前要逐项落实。标"待定"的项，写明了还缺什么才能定。

## 1. 分发

- 只在 GitHub Releases 和官网直装，不上应用商店。所以目前不需要 App 备案和软著，也不用向商店解释"所有文件访问"权限。
- 以后如果要上国内应用商店，需要补齐这些：一个备案主体、App 备案、软著、各商店的隐私合规审核，以及权限用途说明（特别是"所有文件访问"）。
- 官网写各品牌手机直装 APK 的引导，包括华为纯净模式，以及小米、OPPO、vivo 的外部来源安装提示。各品牌的具体步骤待定，要在真机上逐一核实。

## 2. 隐私

- **首次启动**：先显示隐私政策，用户同意之前不申请任何权限。
- **申请权限时说明用途**：

| 权限 | 用途 | 何时申请 |
|---|---|---|
| 定位（精确） | 定点、轨迹、实时位置共享 | 权限页上授权；跳过的话第一次用到定位时再问 |
| 后台定位 | 锁屏后继续记轨迹 | 不申请（2026-11-27）：轨迹由用户在前台点开始，走"定位"类前台服务，锁屏后照样记；被系统停掉后提示"轨迹已中断"，由用户继续；国产手机的后台限制以后再看 |
| 不受电池优化限制 | 熄屏长时间记轨迹时不受省电（Doze）限制 | 权限页上授权；跳过的话第一次记录轨迹时由系统问一次；设置 → 权限里能改。Google Play 只许少数用途申请它，同勘只在 GitHub 发布 |
| 唤醒锁 | 记录轨迹时熄屏后继续处理定位点 | 声明即可 |
| 相机 | 拍照、扫码 | 权限页上授权；跳过的话第一次拍照或扫码时再问 |
| 麦克风 | 录音、口述、语音助手 | 第一次用到时 |
| 所有文件访问 | 读写 `/sdcard/GeoCrew`，就地编辑外部数据 | 首次启动引导时；拒绝也能用，但只能导入 |
| 蓝牙（扫描、连接） | 连接外接 RTK 接收机等仪器 | 第一次连接仪器时 |
| 通知 | 记录轨迹时的常驻通知；同步、下载、长任务的进度，组内提醒 | 权限页上授权；跳过的话第一次用到时再问（现在是第一次记录轨迹时；不授权也照样记，记录条上提示） |
| 安装应用 | 应用内更新 | 第一次安装更新时 |
| 前台服务 | "定位"类用于轨迹；"数据同步"类用于同步、下载和长时间处理（安卓 15 起这类服务每天累计最多 6 小时） | 声明即可 |

- **个人信息清单**（隐私政策里要逐条写明）：
  - 昵称；
  - 位置和轨迹：存在本机；打开位置共享后，发给用户自己选的工作组服务端；
  - 照片、录音、素描：可能含有人脸和声音；存在本机，同步时发给工作组服务端；
  - 推送登记地址；
  - 工作组令牌和 AI Key：只存在本机，用 Keystore 保护；
  - AI 对话：发给用户自己选的模型接口，经过团队代理时的日志规则见下文；
  - 崩溃日志：只存在本机，用户可以自己导出。

  项目方不收集任何数据，也没有中心上报。
- **AI 日志**：团队代理默认只记用量。组长开启查看对话内容时，通知全组，助手界面上一直显示提示；对话内容有保留期限，具体时长待定。
- **数据出境**：用户配置的模型接口在境外时，第一次使用前要告知：发给模型的内容（可能包括记录、位置）会传到境外。团队代理由组长配置，组员要能看到用的是哪个接口。

## 3. 地图

- 项目方不托管、不分发任何地图数据，离线底图和地名库只提供工具。
- 默认底图用天地图，并显示审图号。用户自己添加的图源，由用户自己负责，添加时要提示这一点。
- GCJ-02 / BD-09 做成可选项，默认关闭。反算用的不是官方公开的算法，有法规风险，设置里要说明。
- 导出的地图如果要公开出版，需要另行送审。这一点要在出图功能里提示。

## 4. 数据源条款与署名

| 数据源 | 要求 | 状态 |
|---|---|---|
| OpenStreetMap | ODbL：署名"© OpenStreetMap 贡献者"；用它生成的衍生数据库须以同样条款共享。官方瓦片服务不允许批量下载 | 已知 |
| Copernicus DEM | 免费使用，须按规定署名 | 署名原文待核实 |
| AWS Terrain Tiles | 按各数据来源的要求署名 | 署名清单待核实 |
| 天地图 | 遵守服务条款，显示审图号。服务端 Key 实测没有水印；负责人之前用安卓端 Key 见过影像水印，2026-11-26 复测时安卓端 Key 也没有，推荐哪种随条款一起定 | 待查条款：离线缓存是否允许；服务端 Key 用在手机应用里是否允许 |
| MapTiler、Mapbox、ArcGIS、Azure Maps、谷歌地图平台 | 显示提供方的署名；各家对缓存和离线下载有限制 | 各家条款待核实 |
