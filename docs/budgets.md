# 性能预算

> 状态：草案。除了已注明"已定"的，表里的数字都是**提议**，要在 M1 技术验证和 M2 骨架做出来后实测确认，再由负责人定下来。

## 参考机型

- 一台中端安卓手机，系统为安卓 12 或以上。具体型号待定，由负责人选。
- 不专门适配低端机，但要记下在参考机型上的实测结果，作为每次发布的对比基准。
- 后台轨迹存活要另外在三四个品牌的手机上验证，见[待办](backlog.md)的 M1。

## 提议的目标

| 项目 | 提议的目标 | 怎么测 |
|---|---|---|
| 安装包（arm64） | **已定**（负责人 2026-11-25）：不设上限，能省则省，但不为体积砍功能 | GeoCrew-Native 的 CI 体积表；应用 CI 产物的大小 |
| 冷启动 | ≤ 2 秒打开工程列表，≤ 3 秒进入地图 | 参考机型上测 10 次取中位数 |
| 地图流畅度 | 叠着 10 万个要素平移和缩放时 ≥ 50 帧 / 秒 | M1 的出图验证 |
| 轨迹耗电 | 锁屏、默认记录间隔下，8 小时耗电 ≤ 25% | 参考机型上实测 |
| 内存 | 正常使用地图时 ≤ 500 MB | 用 Android Studio 的分析工具测 |
| 同步 | Wi-Fi 下同步 1000 条修改 ≤ 10 秒（不算附件） | 用模拟器连测试服务端 |

## 规则

- 某项指标比上个版本差了 20% 以上，要在 PR 里说明原因。
- 目标值改动要走 PR，改的是本文件。
