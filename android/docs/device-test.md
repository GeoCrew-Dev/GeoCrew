# 真机测试清单

CI 只能编译、跑单元测试和连一遍服务端，下面这些要在真手机上走一遍。建议两台手机（一台组长、一台组员）加一台电脑浏览器，服务端先用 `scripts/smoke.sh` 确认能用（见服务端仓库 README）。每项后面写结果，有问题记下手机型号、安卓版本和操作步骤。

## 1. 安装与底图

- [ ] 安装 debug APK（Actions 构件 geocrew-debug-apk），首次打开权限提示正常，拒绝定位后再允许也能恢复
- [ ] 填天地图 Key：矢量、影像、地形三种底图和注记都能出图；**确认用的是「浏览器端」还是「服务端」类型的 Key 才能出图，并看图上有没有水印**（这两点还没在真机上核实过）
- [ ] Key 填错时提示看得懂；删掉 Key 后不会残留
- [ ] 自定义底图（XYZ 和 WMS 各一个）能显示；山体阴影开关有效
- [ ] 下载当前范围的离线底图：可暂停、断网自动暂停、杀掉应用后能接着下；飞行模式下离线底图能看

## 2. 野外记录

- [ ] 定位精度圈正常；室内、室外各看一次
- [ ] 定点（当前位置和手点地图）、画线、画面、移动点和节点、撤销
- [ ] 轨迹：开始、锁屏走 10 分钟以上、结束；锁屏期间有通知、轨迹不断；轨迹详情的时间和停留合理
- [ ] 罗盘测产状：和实体罗盘对照一个面，偏差记下来；线状产状也测一次
- [ ] 拍照：照片带方向和位置；在照片上画素描；录音
- [ ] 样品、记录规则（点号规则、必填、至少几张照片）提示正确，「待核对」里能看到缺项
- [ ] 扫码：扫样品标签打开记录，扫邀请码打开加入表单

## 3. 助手与语音

- [ ] 不填 AI 接口：说「定点」会逐项问点号、岩性、产状、描述，提醒拍照并能调起相机，「跳过」有效
- [ ] 离线口令：「打点 花岗岩 120∠35」「今天做了多少」「D012 附近有哪些点」「大家在哪」「这里是什么地层」「撤销」
- [ ] 语音播报能开关、调语速；免手持模式读完问题会自动听
- [ ] 下载离线识别模型后断网说话能转写，常用岩性词能被纠正
- [ ] 填上自己的 AI 接口后能随口说；删除类操作会先弹确认卡

## 4. 工作组（两台手机）

- [ ] 组长建组，组员扫码或输邀请码加入；组员看到组长共享的表单、图例、参考图层、记录规则
- [ ] 双方互相看到实时位置和半小时足迹
- [ ] 两人同时改同一条记录，冲突提示合理，没有丢数据
- [ ] 一台断网改几条、拍几张照片，恢复网络后自动上传，另一台收到
- [ ] 讨论、紧急消息、点名（报平安和求助）、外出报备超时推送、公告推送都能收到
- [ ] 组长审核通过和退回；任务指派后组员能改状态
- [ ] 「接入 AI 工具」给出的地址和令牌，在电脑的 MCP 客户端里能用；撤销后失效

## 5. 网页查看页（电脑浏览器）

- [ ] 用查看链接打开：记录、轨迹回放、照片、消息、图例、参考图层都对
- [ ] 下载 KML、GeoPackage、产状表、工作量表，用 QGIS 或表格软件打开没有乱码

## 6. 导入导出

- [ ] 导入 Shapefile（GBK 属性和高斯投影各一个）、GeoPackage、KML、GPX
- [ ] 导出 DXF 在 CAD 里打开，图层和注记正常；地图出图 PDF、剖面柱状图 PDF 比例尺正确
- [ ] 分享一条记录到微信，文字和照片都在
