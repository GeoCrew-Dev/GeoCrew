# 同勘 GeoCrew 协议

同勘 GeoCrew 是一款开源的野外地质移动工具，把地图工具、轻量 GIS 和小组实时协同放在同一个 Android 应用里。

本目录存放：

- **协同协议**：客户端与自部署服务端之间的数据格式、接口和鉴权约定（`docs/protocol-v0.md`），以及机器可读的 OpenAPI 描述（`docs/openapi.yaml`）。
- **分析插件接口**：其他安卓应用如何给同勘提供空间分析工具（`docs/plugins.md`），只交换 GeoJSON 文件。
- **一致性检查**：从外部跑一遍、确认某个服务端按协议工作的命令行工具（`conformance/`），主仓库的 CI 用它检查 `server/`。
- **版本与发布**：版本号规则、发布附带的文件和 `SHA256SUMS`、客户端与服务端怎样检查和安装更新（`docs/releases.md`）。
- **动作层与 AI 助手**：客户端把功能登记为可撤销的动作，常用口令、引导式定点和 AI 模型都通过它操作；风险类别、确认规则和组长限制（`docs/actions.md`）。
- **旧规划**：重写前的功能分期与技术选型（`docs/roadmap.md`），留作参考。现行规划见主仓库的 [`docs/charter.md`](../docs/charter.md)，架构决策见 [`docs/adr/`](../docs/adr/)。

任何人都可以按本协议实现自己的服务端或客户端。官方参考实现和本协议在同一个主仓库里：

| 目录 | 内容 |
| --- | --- |
| [`android/`](../android) | Android 客户端（旧代码，待重写） |
| [`server/`](../server) | Linux 自部署服务端（Docker） |

## 设计原则

1. **离线优先**：所有记录先存本地，有网再同步，不依赖服务端也能完整使用单机功能。
2. **数据自主**：服务端由使用者自行部署，项目方不托管任何用户数据。
3. **开放格式**：几何与属性统一使用 GeoJSON（RFC 7946），可直接导入 QGIS / ArcGIS。
4. **协议先行**：接口变更先改本目录的文档，再改实现。
