# 同勘 GeoCrew 项目规划

> 状态：草案 v0.1（2026-11-24）。随开发推进持续更新。

## 1. 定位

一款面向野外地质与地理调查的开源 Android 工具，三块能力围绕"地图 + 野外记录"这个主干展开：

| 能力 | 做什么 | 不做什么 |
| --- | --- | --- |
| 地图工具 | 天地图等在线/离线底图、实时定位、轨迹 | 导航、POI 搜索 |
| 野外 GIS | 点线面采集、属性、拍照、产状、量算、缓冲区、插值插件 | 复杂空间分析（留给桌面端） |
| 小组协同 | 组长建工作区，组员扫码加入；共享位置与记录；挂在地图对象上的讨论 | 通用聊天软件 |

## 2. 分期

### 第一阶段：单机野外记录（MVP）

- 天地图底图（矢量、影像、地形 + 注记），用户填写自己的 API Key
- 实时定位，显示精度圈
- 定点：一键在当前位置打点，或在地图上手动选点
- 轨迹记录：开始/暂停/结束，后台持续记录
- 点线面绘制与编辑，自定义属性表单
- 拍照并关联到要素，照片记录方位角与位置
- 电子地质罗盘：用手机传感器测走向、倾向、倾角，生成带产状符号的地质点
- 导入/导出 GeoJSON、KML、GPX，导出 Shapefile
- 本地工程管理（一个工程一个文件夹）

### 第二阶段：小组协同

- 连接自部署服务端，组长创建工作区并生成邀请码 / 二维码
- 组员加入后实时看到彼此位置
- 要素、照片双向同步，离线编辑后自动合并
- 权限：组长 / 成员 / 只读

### 第三阶段：地图上的交流

- 在任意要素上发起讨论，所有组员点开要素即可看到
- 工作区内的简单消息流，消息可"定位到地图"
- 推送通知（自部署服务端可选接入）

### 第四阶段：开放生态

- GIS 工具插件接口（输入输出 GeoJSON），首个插件：IDW / 克里金插值
- 现场自适应采样：按克里金估计方差提示下一个采样位置
- 离线切片包的生成与导入

## 3. 架构

```
┌──────────── Android 客户端 ────────────┐        ┌──── 自部署服务端 (Linux) ────┐
│ UI (Jetpack Compose)                   │        │ HTTP API  (REST, JSON)      │
│ 地图 (MapLibre Native + 天地图 WMTS)    │ ─────▶ │ 实时通道  (WebSocket)        │
│ 本地库 (Room / SQLite, GeoJSON 几何)    │ ◀───── │ 存储      (SQLite 默认,      │
│ 同步引擎 (离线队列 + 版本号合并)         │        │           PostGIS 可选)      │
│ 传感器 (定位 / 罗盘 / 相机)              │        │ 文件      (照片, 本地磁盘)    │
│ 插件接口 (GeoJSON in/out)               │        └────────────────────────────┘
└────────────────────────────────────────┘
```

## 4. 技术选型

| 模块 | 选择 | 理由 |
| --- | --- | --- |
| 客户端语言 | Kotlin | Android 官方推荐 |
| UI | Jetpack Compose + Material 3 | 简洁界面、开发效率高 |
| 地图引擎 | MapLibre Native Android | 开源（BSD），支持 WMTS 栅格瓦片、矢量瓦片与离线 |
| 本地存储 | Room（SQLite） | 稳定，几何以 GeoJSON 文本存储 |
| 最低版本 | Android 10（API 29） | 覆盖当前野外常用机型，不适配老旧系统 |
| 服务端语言 | Go | 单一可执行文件，Docker 镜像小，部署简单 |
| 服务端存储 | SQLite（默认）/ PostgreSQL + PostGIS（可选） | 小组规模 SQLite 足够，大型团队可换 PostGIS |
| 实时通道 | WebSocket | 浏览器和移动端都原生支持，无需额外中间件 |
| 部署 | Docker / docker compose | 一条命令启动 |
| 持续集成 | GitHub Actions | 客户端出调试版 APK，服务端跑测试并构建镜像 |

## 5. 坐标与底图约定

- 数据统一存储经纬度（CGCS2000 / WGS84，二者在野外精度下可视为一致），GeoJSON 坐标顺序为 `[经度, 纬度, 高程]`。
- 天地图使用 Web 墨卡托（`_w`）瓦片接入 MapLibre。
- 天地图 API Key 由用户自行申请并填写，不写入代码仓库。

## 7. 进展（2026-11）

| 模块 | 状态 |
| --- | --- |
| 协议 v0 | 工作区、邀请、成员角色、要素增量同步（seq）、冲突规则、修改历史、附件、实时通道、共享设置（记录表单）、GeoJSON 导出、记录讨论与组内消息；附 OpenAPI 描述 |
| 服务端 | Go + SQLite 参考实现，覆盖协议 v0 全部接口；单文件部署，含加入限流、可关闭新建、运维命令（列出、备份、导出、吊销） |
| 安卓：工程 | 多工程管理，地图、记录、工具、工作组都在工程内；工程包导入导出；每个工程有自己的底图、视图、说明和记录表单 |
| 安卓：地图 | 天地图矢量/影像/地形与 OSM，用户自填 Key 并可校验；任意 XYZ 自定义底图；产状符号与倾角标注；前往坐标（十进制、度分秒、带东经北纬等写法） |
| 安卓：野外记录 | 定位与精度圈、打点、绘制线面、轨迹记录、属性与照片、记录表单、产状罗盘（多次读数平均、磁偏角校正）；GeoJSON/KML/GPX/Shapefile/CSV 导入导出 |
| 安卓：分析 | 赤平投影（极点、大圆、Fisher 统计）、走向玫瑰图、按参数生成表单的分析工具 |
| 安卓：小组协同 | 同步引擎、建组/入组（二维码与链接）、成员管理、组员实时位置、记录修改历史与恢复、表单同步、记录讨论与组内消息（离线可写） |

尚未开始：推送通知（第三阶段）、IDW / 克里金插值与自适应采样（第四阶段）、离线切片包。
